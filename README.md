# Greenfoot Combat Game

A Java/Greenfoot game prototype that explores player movement, enemies, collision detection, equipment, and animated weapon combat.

## Highlights

- Player and enemy actors with movement logic
- Equippable sword and anchor weapons
- Multi-frame swinging animations
- Vector and point classes for movement calculations
- Original game-world setup and sprite integration

## Technologies

- Java
- Greenfoot
- Object-oriented programming

## Run the Project

1. Install [Greenfoot](https://www.greenfoot.org/download).
2. Download or clone this repository.
3. Open `project.greenfoot`.
4. Compile the scenario and select **Run**.

## Project Structure

- `MyWorld.java` – builds the game world
- `Player.java` and `Enemy.java` – character behavior
- `Sword.java` and `Anchor.java` – equipment and attack behavior
- `Point2D.java` and `Vector2D.java` – movement mathematics
- `images/` – game sprites and animation frames

## What I Practiced

This project strengthened my understanding of object-oriented design, real-time update loops, animation, collision behavior, and organizing multiple interacting game objects.
