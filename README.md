# Greenfoot Combat Game

A Java game prototype that explores real-time combat mechanics in the Greenfoot environment. The player can move through the world, equip a weapon, swing an animated anchor, and interact with enemies that spawn over time.

## Features

- Keyboard-controlled player movement
- Enemy spawning and movement
- Equipment and weapon handling
- Multi-frame swinging animation
- Collision and distance calculations
- Custom vector and point utilities

## Technologies

- Java
- Greenfoot
- Object-oriented programming
- 2D sprite animation

## Run the project

1. Install [Greenfoot](https://www.greenfoot.org/download).
2. Download or clone this repository.
3. Open `project.greenfoot`.
4. Compile the scenario and select **Run**.

## Project structure

- `Player.java` — player movement and interaction
- `Enemy.java` — enemy behavior
- `Anchor.java` and `Sword.java` — weapon mechanics
- `MyWorld.java` — world setup and enemy spawning
- `Point2D.java` and `Vector2D.java` — movement math helpers
- `images/` — game sprites and animation frames
